# Important Sidebar Infrastructure

Adds small decorative icons to the Obsidian ribbon.

Despite the name, the infrastructure is not particularly important.

## Features

- add any number of custom icons to the left ribbon
- use bundled plugin icons or images from the vault
- enable or disable icons individually
- reorder icons
- adjust icon size, opacity and spacing
- choose between normal image rendering and monochrome mask rendering
- use Obsidian theme colors or a custom tint
- apply global styling to all icons
- override styling for individual icons when needed

Supported image formats include:

- PNG
- SVG
- WebP
- JPG / JPEG
- GIF

## Installation

Copy the plugin folder to:

.obsidian/plugins/important-sidebar-infrastructure

Then reload Obsidian and enable Important Sidebar Infrastructure in:

Settings → Community plugins → Usage

Open the plugin settings and add a new icon.
For bundled icons, select an image from the available plugin assets.
For vault icons, provide a path relative to the vault root, for example:

_attachments/icons/tapir.png

Icons can then be reordered, enabled or disabled, resized and styled directly from the plugin settings.
